Pipeline Engine
EB-40 · CONTEXT ENGINE
🧠 Query Understanding Engine
Parses prompts, extracts Indian AEC temporal bounds, normalizes Hinglish/Telugu, outputs QueryPlan.
Capabilities
Intent: LOOKUP, NUMBER, INVESTIGATION, TIMELINE
Indian Dates: "Since Diwali", "Q2 FY26", "Last Month"
Multi-lingual Lexicon (Telugu: "entha karchu", Hinglish)
EB-49 · QUERY ROUTER
⚡ Query Router
Routes query to Fast Path (p95 < 3s, LiteLLM Fast) vs Deep Investigation (p95 < 20s, LiteLLM Reason).
Routing Rules
Fast: Factoid, Contact, Drawing No (2k max tokens)
Deep: Root-cause, Disputes, Delays (8k tokens + Graph)
Token Cost & Latency SLA Tracker
EB-43 · HYBRID RETRIEVAL
🔍 Hybrid Retrieval & RRF
Parallel Qdrant Dense, OpenSearch BM25, and Sparse search with Reciprocal Rank Fusion (k=60).
Search Channels
Qdrant Vector (BGE-M3 1024-dim dense embeddings)
OpenSearch BM25 with AEC token analyzers
Mandatory TenantContext & OpenFGA pre-filter
EB-45 · RERANKER
📊 Cross-Encoder Reranker
Scores top 50 fused candidates with bge-reranker-v2-m3; selects top 15 evidence spans (< 400ms SLA).
Evaluation
Batch scoring (batch_size=32)
nDCG@10 Golden Set Metric Gain: +18.4%
Synthesis & Verify
EB-46 · COMPRESSION
🗜️ Context Compressor & Cache
Filters near-duplicate forwarded messages (Jaccard shingling), enforces token budget, caches answers.
Compression Rules
Deduplication: Jaccard shingle similarity > 0.85
Preserves XML candidate tags and evidence IDs
Multi-tenant cache keyed on (tenant, user, question, ver)
EB-47 · REASONER
🧩 Answer Reasoner
Generates typed AnswerContract schema; isolates documents in passive XML; binds figures to SQL tools.
Safety & Prompts
Passive XML tags eliminate Prompt Injection
Strict SQL origin validation for financial figures
Self-correction retry loop on schema validation error
EB-48 · EVIDENCE VERIFIER
✅ Evidence Verification Engine
Splits propositions, checks number/date exact matches, flags polarity contradictions, ensures ≥0.95 faithfulness.
Audit Engine
Atomic Claim Splitting & Entailment Check
Indian Currency & Float Tolerance Matching
Routes unsupported claims to unknowns / conflicts
