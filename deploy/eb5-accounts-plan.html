2. Guardrails from day one

  • Never use AWS root day-to-day; create one admin user in IAM Identity Center.
  • Provider spend caps sit below the LiteLLM per-tenant budgets, which alert at 70% and 90%.
  • No secret in code or in Notion. gitleaks in CI (free) catches accidental commits.
  • Rotate API keys every 90 days; recovery codes printed and stored offline.
  • Two FIDO2 keys (one kept off-site) for Google, AWS, GitHub, registrar and Cloudflare.
